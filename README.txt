Python Programs — Smart Coders 112 Practice Problems

This folder contains 112 separate beginner-friendly Python programs, numbered 001.py through 112.py, following the question list in the uploaded ds.docx.

Notes:
- Run each file separately with Python 3.
- A few questions do not specify exact rules (for example, ticket pricing, electricity slab rates, ATM minimum balance, and scholarship criteria). Those files use clearly commented sample assumptions; adjust them to match your teacher's required values.
- Problem 30 uses if/elif because Python does not have a traditional switch-case syntax in the same way as C; modern Python has match/case, but if/elif is beginner-friendly.
- Pattern questions can vary in spacing across printed copies, so the programs implement the named pattern in the question.
